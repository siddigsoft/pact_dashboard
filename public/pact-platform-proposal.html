02 — Problem Statement
Sudan field operations
face unique compounding challenges

التحديات الفريدة للعمليات الميدانية في السودان

📋

Fragmented Planning

MMP data scattered across Excel files, WhatsApp groups, and email chains. No single source of truth for site coverage, visit status, or team assignments across multiple geographic hubs.

💸

Manual Financial Reconciliation

Bank transfer receipts processed manually — 5+ minutes per receipt, high error rates in Arabic account numbers, no duplicate detection, and no audit trail for donor reporting.

📡

Connectivity & Offline Gaps

Field teams in remote locations (North Darfur, South Kordofan, Blue Nile) have intermittent or no internet access during site visits — standard web tools completely fail here.

👁️

No Real-Time Visibility

Programme managers have no live view of which sites are covered, which teams are in the field, where bottlenecks are forming, or what the financial position is at any given moment.

📑

Compliance & Audit Risk

Donor requirements (USAID, EU, UNOCHA) demand structured transaction records, geographic coverage evidence, quality scores, and timestamped approvals — impossible to produce from paper-based systems.

🔄

Complex Multi-Role Workflows

Operations involve Super Admins, Hub Managers, Coordinators, Data Collectors, Finance Officers, and external validators — with no shared system to track approvals, assignments, and handoffs.

1

Upload receipts

AI processes in batches

Real-time amber flagging of any repeated Transaction ID — prevents double-counting before export

User Manual — Section 2

MMP Upload, Dispatch & Site Visits

MMP UPLOAD (ADMIN / HUB MANAGER)
1

Prepare Excel MMP file

Format the site list to PACT's MMP template. Required columns: Site Name, Location, State, Locality, Coordinates.

2

Upload via MMP section

Go to Operations → MMP Files → Upload New. The system validates every row — errors are listed for correction before saving.

3

Assign to hubs

After upload, assign site groups to Hub Managers. They see only their assigned sites.

4

Open for dispatch

Activate the MMP cycle. Coordinators can now dispatch sites to data collectors.

DISPATCH (COORDINATOR)
1

Open site list

Go to Operations → Site Visits → Dispatch. Filter by hub, state, or locality. The map view shows all unassigned sites.

2

Assign to data collector

Select a site → choose a data collector from the dropdown (filtered by availability and capacity). The Smart Dispatch system highlights the best match.

3

Data collector notified

The data collector receives a push notification on their phone — the visit appears in their task list immediately.

FIELD VISIT (DATA COLLECTOR)
1

Claim or receive site

Open the mobile app → My Visits → tap the assigned site. First-claim sites can be self-assigned from the available pool.

2

GPS check-in at site

On arrival, tap Check In. The GPS coordinates are recorded. If not within the required proximity, a warning is shown.

3

Complete the form

Fill questionnaire fields, upload photos, record beneficiary count. Works fully offline — data saved locally until sync.

4

Submit & sync

Tap Submit. If online — immediate sync. If offline — syncs automatically when connectivity returns. Supervisor notified.

User Manual — Section 3

Financial Workflows — Advances, Costs & Scanner

ADVANCE REQUESTS
1

Submit advance request

Go to Finance → Advances → New Request. Enter amount, purpose, and expected return date. Attach supporting documents.

2

Two-tier approval

Hub Manager approves first → Finance Officer approves second. You receive a notification at each stage.

3

Fund disbursement

On final approval, the amount is added to your wallet. A signed digital certificate is generated automatically.

4

Settlement

Submit operational cost receipts against the advance. The system auto-deducts from your wallet balance. Remaining balance is returned.

OPERATIONAL COST SUBMISSION
1

Create submission

Go to Finance → Operational Costs → New. Select category (transport / accommodation / fuel / per diem, etc.) and enter amount.

2

Attach evidence

Upload receipt photos. For bank transfers, use the Transaction Scanner to extract details — paste the transaction ID.

3

Sign & submit

Draw your digital signature on the submission form. Submit — the Coordinator and Finance Officer are notified immediately.

4

Track approval status

View the approval chain status in real time. Once approved, a PDF certificate with your digital signature is downloadable.

TRANSACTION SCANNER
1

Open scanner

Go to Finance → Transaction Scanner. Drag & drop receipt screenshots into the upload zone — or click to browse.

2

Wait for AI extraction

Each receipt is processed in ~30 seconds. Watch the live status per row (Waiting → Reading → Done). Errors show a Retry button.

3

Review & clean

Check the table. Remove duplicates (amber rows) using the × button. Add more images if needed — batches can be combined.

4

Save & export

Click Save to store in the database. Click All (N) to export full Excel, or Export by Account to filter by recipient.

User Manual — Section 4

Troubleshooting & Common Questions

COMMON ISSUES
  • Can't log in — Check caps lock; reset password via "Forgot Password". If 2FA fails, use backup codes from your profile settings.
  • Site visit not syncing — Open the app, go to Settings → Force Sync. If still stuck, check connectivity and retry.
  • Scanner AI quota exhausted — Wait until midnight Pacific (08:00 Sudan time). Your images are preserved — click Retry All tomorrow.
  • Excel export doesn't download — Allow downloads in browser settings. Try Chrome if using another browser.
  • Approval stuck — Contact the next approver — they may not have seen the notification. Admins can escalate via the Super Admin panel.
FREQUENTLY ASKED
  • Can I use the platform on my phone? Yes — the web app is fully mobile-responsive. The Flutter app offers full offline capabilities.
  • What happens if internet cuts out mid-visit? The mobile app saves all data locally. When connectivity returns, it syncs automatically — no data is lost.
  • Can two people work on the same session? Yes — the platform supports multiple concurrent sessions. Real-time updates are visible to all users.
  • How do I add a new staff member? Admins go to Staff Directory → Add New Staff. Assign a role, hub, and email. The system sends onboarding instructions.
  • Can I correct AI-extracted data? Inline editing is on the roadmap. Currently, correct the value in the exported Excel file after download.
GETTING HELP
  • In-app Help — Click the ? icon in the sidebar to open the Help & Support System with guided walkthroughs.
  • Support Contacts — Admin-managed contact list accessible from the mobile app home screen and the web sidebar.
  • Broadcast Announcements — Check the Notifications panel for important updates from PACT HQ broadcast by admins.
  • Activity Audit — Super Admins can view any user's recent activity log from the Super Admin Data Management Centre.
  • System status — The "All Systems Operational" indicator on the login page shows real-time platform health.
SECURITY TIPS
  • Enable TOTP 2FA on your account for maximum security
  • Never share your password — use the built-in password reset
  • Log out from shared devices — session persists until logout
