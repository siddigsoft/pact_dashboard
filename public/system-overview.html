Flexible Workflows · سير عمل مرن

Each project has its own workflow

كل مشروع له سير عمل خاص به قابل للتخصيص

GFA GFA CBT e-BSFP AIM PDM MDM WHM

⚙️ Configurable per project

Activity Type — site visit category, check-list, and required evidence defined per project

Add-On Modules — MDM and WHM can be toggled ON/OFF independently for any project in the MMP

Fee Formula — each activity type has its own rate: flat, ×2 multiplier, or ÷7 per-visit cycle

Approval Steps — two-tier (Supervisor → Admin) or single-tier depending on project rules

Permit Requirements — certain localities require a permit before dispatch; toggled per MMP

Reporting Template — each project generates different analytics views and export formats

What can be customized

📋 Visit Type ✅ MDM Add-On 🏭 WHM Add-On 💰 Fee Rate 🔐 Approval Tiers 📍 GPS Radius 🗺️ Permit Zones 📊 Report Format 📅 Visit Frequency 👥 Team Assignment

💡 Why this matters

WFP Sudan runs multiple concurrent programmes across different states. Each has unique operational rules. PACT lets admins configure each project independently — without creating separate systems.

يدير برنامج الأغذية العالمي في السودان برامج متعددة في وقت واحد، لكل منها قواعده الخاصة.

📶

Full offline mode: Enumerators complete visits, capture GPS & photos, and submit reports — all stored locally on the device and synced automatically when connectivity is restored.

📍 Visit Lifecycle

📋

Dispatch

Site assigned from MMP to enumerator — with GPS coordinates, activity type, and required checklist

🗺️

Navigate & Arrive

App confirms proximity using GPS radius match — prevents false visits from wrong locations

📸

Complete & Evidence

Fill activity form, capture timestamped photos, record beneficiary counts and activity notes

✅

Submit & Sync

Report submitted — synced live to web dashboard; supervisor notified instantly for review

💳

Fee Calculated

Visit fees auto-calculated by activity type (PDM ÷7, MDM ×2, WHM ×2) and credited to wallet

💸 Advance-to-Receipt Flow

1

Enumerator requests transport advance before field deployment

2

Supervisor reviews — approves or rejects with reason

3

Admin authorizes final disbursement from budget

4

Funds transferred to enumerator wallet with signed receipt

5

Enumerator confirms receipt on mobile — bilingual confirmation

6

Advance deducted from visit fees — auto-reconciled in system

🔁 Reclaim & Gap Tracking

When a site is reclaimed, any disbursed advances linked to it are automatically flagged. Finance admins see a live reconciliation dashboard with pending exposure totals and bulk resolve tools.
