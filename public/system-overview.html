Flexible Workflows · سير عمل مرن

Each project.
Its own workflow.

كل مشروع له سير عمل خاص به — قابل للتخصيص بالكامل دون الحاجة إلى برمجة

GFAGFA CBT e-BSFPAIM PDMMDMWHM

⚙️ What admins configure per project

Activity Type & Checklist — visit category, evidence requirements, and beneficiary count fields defined per project

Add-On Modules — MDM and WHM toggled independently per MMP — no additional systems needed

Fee Formula — flat rate, ×2 multiplier (MDM/WHM), or ÷7 per-cycle (PDM) — set per activity

Approval Chain — single-tier or two-tier (Supervisor → Admin) based on project rules

Permit Requirements — certain localities require a permit before dispatch — toggled per MMP

Reporting Template — each project generates its own analytics views and export formats

Customizable parameters

📋 Visit Type ✅ MDM Add-On 🏭 WHM Add-On 💰 Fee Rate 🔐 Approval Tiers 📍 GPS Radius 🗺️ Permit Zones 📊 Report Format 📅 Visit Frequency 👥 Team Assignment

💡 Why this architecture matters

PACT runs multiple concurrent programmes across different countries. Each has unique operational rules. Command Center lets each office configure their projects independently — without building separate systems or writing code.

💸 Advance-to-Receipt Flow

1

Enumerator requests transport advance before field deployment

2

Supervisor reviews — approves or rejects with documented reason

3

Admin authorizes final disbursement from budget allocation

4

Funds transferred to enumerator wallet with signed digital receipt

5

Enumerator confirms receipt on mobile — bilingual confirmation screen

6

Advance auto-deducted from visit fees — reconciled in system with zero manual entry

🔁 Reclaim & Financial Gap Tracking

When a site is reclaimed, disbursed advances linked to it are automatically flagged. Finance admins see a live reconciliation dashboard with bulk resolve and write-off tools — with PDF certificates generated per case.
