Web Platform — Core Features

المنصة الإلكترونية — الميزات الأساسية
📋

Monthly Monitoring Plans (MMP) خطط المراقبة الشهرية

  • Excel upload with 40+ column name variants (any case, with/without "Use")
  • Partial update — correct specific states or localities without affecting others
  • Multi-tier verification workflow (Admin → Data Team → Supervisor)
  • MMP recall & reclaim from coordinators with audit trail
  • Version history and activity log per MMP
  • Auto-detection of MDM, WHM, and PDM flags per site
📍

Site Visit Management إدارة زيارات المواقع

  • Smart dispatch with GPS proximity matching
  • First-claim system — enumerators claim available sites
  • Visit postponement and auto-release after deadline
  • Date-range visits and follow-up tracking
  • Coverage gap notifications and cycle comparison
  • Per-hub performance scorecards
💰

Financial Management الإدارة المالية

  • Transportation advance requests with two-tier approval
  • Operational cost submissions — 9 expense categories
  • Digital signatures and PDF certificate generation
  • Wallet system with full transaction history per enumerator
  • Confirmation Audit — tracks fund receipt confirmation
  • Reclaim Impact Report with write-off workflow and audit
📊

Reporting & Analytics التقارير والتحليلات

  • Coverage Analytics Dashboard with predictive alerts
  • Transportation Advance Report — by State, Project, MMP
  • Budget vs. actual comparison with variance analysis
  • Site Visit Quality Scoring
  • Data Export Center — bulk export to Excel/PDF
  • Reconciliation dashboard with aging reports
🏃

Activity Tracking (MDM / WHM / PDM) تتبع الأنشطة الميدانية

  • MDM — Market Diversion Monitoring, DM sites only, auto-enabled from MMP flag
  • WHM — Warehouse Monitoring, DM & AIM sites, auto-enabled from MMP flag
  • PDM — Post Distribution Monitoring, independent activity
  • Fee formula: PDM = questionnaires ÷ 7, MDM = ×2, WHM = ×2
  • Total fee card shown in visit report matching mobile calculation
  • MDM questionnaire count and WHM warehouse name captured
🔔

Notifications & Communications الإشعارات والتواصل

  • Real-time in-app bell notifications with WhatsApp-style toasts
  • Email notifications via IONOS SMTP — bilingual templates
  • Daily/weekly digest emails for pending actions
  • Broadcast Center — announce to all users or specific roles
  • Browser badge updates and auto-cleanup
  • Read receipts and quick action support
📱

Activity Fee Calculation Rules

قواعد احتساب رسوم الأنشطة
Activity / النشاط Type / النوع Eligible Sites / المواقع المؤهلة Trigger / الشرط Fee Formula / صيغة الرسوم
GFA / GFA In-Kind Base DM sites Main activity = GFA × 1 site visit
GFA CBT / CBT Base DM sites Main activity = GFA CBT × 1 site visit
AIM / TSFP / PSN / FFA / SF / THR / PHL Base AIM sites Main activity = any AIM type × 1 site visit
PDM — Post Distribution Monitoring Independent PDM sites Main activity = PDM Questionnaires ÷ 7 (floor)
MDM — Market Diversion Monitoring Add-On DM sites only Use Market Diversion = Yes Fixed × 2 site visits
WHM — Warehouse Monitoring Add-On DM & AIM sites Use Warehouse Monitoring = Yes Fixed × 2 site visits
