## Deployment Instructions

### 1. Verify Environment
```bash
flutter doctor -v
cd PACT_mobile
flutter pub get
```

### 2. Firebase Setup
```bash
# Place google-services.json in android/app/
cp google-services.json android/app/

# Verify initialization
flutter run
# Check logs: "Firebase Analytics initialized"
```

### 3. Build Release APK
```bash
flutter build apk --release --split-per-abi
# Output: build/app/outputs/apk/release/
```

### 4. Run Tests
```bash
flutter test --coverage
# Expected: 104+ tests passing, 80%+ coverage
```

### 5. Verify Analytics
1. Open Firebase Console
2. Go to Analytics → Realtime
3. Open app on device
4. Interact with screens
5. Verify events appear in console
