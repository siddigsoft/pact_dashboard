## 1. المقدمة

### 1.1 حول مركز قيادة PACT

**مركز قيادة PACT** هو مركز قيادة العمليات الميدانية المركزي المصمم للإدارة الشاملة للعمليات الميدانية الإنسانية والتنموية. تعمل المنصة كمركز قيادة موحد يمكّن المنظمات من التخطيط والتنسيق والتنفيذ ومراقبة جميع الأنشطة الميدانية من واجهة متكاملة واحدة.

```
╔═══════════════════════════════════════════════════════════════════════════════╗
║                         مركز قيادة PACT                                       ║
║                  مركز قيادة العمليات الميدانية المركزي                         ║
╠═══════════════════════════════════════════════════════════════════════════════╣
║                                                                               ║
║   ┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐   ║
║   │   تخطيط     │───►│  موافقة    │───►│   تنسيق    │───►│   متابعة    │   ║
║   │   (MMPs)    │    │  (سير عمل) │    │  (الفرق)   │    │  (مراقبة)   │   ║
║   └─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘   ║
║         │                  │                  │                  │            ║
║         └──────────────────┴──────────────────┴──────────────────┘            ║
║                              ▼                                                ║
║                    ┌─────────────────────┐                                    ║
║                    │  لوحة القيادة الموحدة │                                    ║
║                    │  التحكم في الوقت الحقيقي│                                    ║
║                    └─────────────────────┘                                    ║
║                                                                               ║
╚═══════════════════════════════════════════════════════════════════════════════╝
```

### 2.2 مكدس التقنيات

| الطبقة | التقنية | الغرض |
|--------|---------|-------|
| **الواجهة الأمامية** | React 18, TypeScript | إطار واجهة المستخدم |
| **التنسيق** | Tailwind CSS, Shadcn UI | مكتبة المكونات |
| **الحالة** | TanStack Query, Context API | إدارة البيانات |
| **التوجيه** | React Router DOM v6 | التنقل |
| **الخلفية** | Supabase (PostgreSQL) | قاعدة البيانات والمصادقة |
| **الوقت الحقيقي** | Supabase Realtime, WebRTC | التحديثات المباشرة |
| **الهاتف** | Capacitor | التطبيقات الأصلية |
| **البريد** | IONOS SMTP | الإشعارات |
| **الفيديو** | Jitsi Meet, WebRTC | مكالمات الفيديو/الصوت |
| **الخرائط** | Leaflet | GPS والموقع |

### 3.2 تعريفات الأدوار الكاملة

| الدور | المعرف | الفئة | الوصف | الصلاحيات الرئيسية |
|-------|--------|-------|-------|-------------------|
| **المدير العام** | `superadmin` | إداري | تحكم كامل في النظام مع جميع الصلاحيات | جميع الموارد، جميع الإجراءات، تكوين النظام |
| **المدير** | `admin` | إداري | إدارة المستخدمين والأدوار | CRUD المستخدمين، تعيين الأدوار، الإعدادات |
| **مدير المشروع** | `project_manager` | إداري | إشراف كامل على المشروع مع موافقة الميزانية وتنسيق الفريق | CRUD/موافقة المشاريع، موافقة الخطط، موافقة المالية، موافقة المحافظ |
| **مدير العمليات الميدانية** | `fom` | ميداني | قيادة العمليات الميدانية وإدارة زيارات المواقع وتنسيق الفريق | CRUD/موافقة زيارات المواقع، تحديث الخطط، إدارة الفريق |
| **قائد العمليات الأول** | `senior_operations_lead` | إداري | قيادة عليا مع صلاحية تجاوز الميزانية للمعاملات المقيدة | تجاوز الميزانية، الموافقات النهائية، تجاوز المحفظة |
| **المشرف** | `field_supervisor` | ميداني | إشراف على الفريق وإدارة جامعي البيانات ومراجعة التقديمات | تعيين/تحديث زيارات المواقع، تحديث الخطط، مراجعة التقديمات |
| **منسق الولاية** | `state_coordinator` | ميداني | تنسيق الأنشطة على مستوى الولاية وإدارة زيارات المواقع وتعيينات العمل | CRUD/تعيين زيارات المواقع، تحديث الخطط، مراقبة على مستوى الولاية |
| **موظف المالية** | `finance_officer` | مالي | العمليات المالية ومعالجة المدفوعات وموافقات المصروفات | CRUD/موافقة المالية، التقارير، الدفعات المقدمة |
| **جامع البيانات** | `data_collector` | ميداني | جمع البيانات الميدانية وتنفيذ زيارات المواقع وتقديم التكاليف | المطالبة/إتمام زيارات المواقع، تقديم التكاليف، رفع الصور |
| **تقني/ICT** | `ict` | تقني | الدعم التقني وصيانة النظام وحل المشكلات | تحديث المستخدمين، الإعدادات، سجلات التدقيق، تكوين النظام |
| **المراجع** | `reviewer` | إداري | ضمان الجودة ومراجعة البيانات والتقديمات | وصول للقراءة فقط، التحقق من البيانات، مراجعة الامتثال |
| **محلل البيانات** | `data_analyst` | تقني | تحليل البيانات وإنشاء التقارير والرؤى | قراءة/إنشاء التقارير، تصدير البيانات، التحليلات |

### 6.2 إدارة خطط المراقبة الشهرية - واجهة التصفح

تتميز صفحة إدارة خطط المراقبة الشهرية بنظام تصفح شامل مع علامات تبويب رئيسية وفرعية:

#### علامات التبويب الرئيسية

| علامة التبويب | الأيقونة | الوصف | الوصول |
|---------------|----------|-------|--------|
| الخطط الشهرية | 📋 | قائمة خطط المراقبة الشهرية ورفعها | الجميع |
| إدارة المواقع | 📍 | سجل المواقع والتحقق | المديرون، مديرو العمليات |
| المالية | 💰 | موافقات التكاليف ولوحة المدفوعات | المديرون، المالية، مديرو العمليات |
| متتبع سير العمل | 📊 | تتبع تقدم الخطة ومعالم المواقع | الجميع |

#### علامات التبويب الفرعية

**علامات الخطط الشهرية الفرعية:**
- **قائمة الخطط**: جميع الخطط المتاحة
- **رفع الخطط**: رفع ملفات CSV جديدة

**علامات إدارة المواقع الفرعية:**
- **سجل المواقع**: قاعدة بيانات المواقع الرئيسية
- **إدارة المواقع**: التحقق والموافقة على المواقع الجديدة
- **تحويل المنسقين** (مديرو العمليات): مواقع للمراجعة
- **مواقع مرسلة للمنسقين** (مديرو العمليات): مواقع محولة
- **الزيارات المكتملة** (مديرو العمليات): زيارات منتهية

**علامات المالية الفرعية:**
- **موافقات التكاليف**: قائمة انتظار موافقات التكاليف
- **لوحة المدفوعات**: حالة الدفع والتحويلات

**علامة متتبع سير العمل الفرعية:**
- عرض تقدم جميع الخطط والمواقع

### 6.3 دعم التدويل (i18n)

تدعم المنصة التبديل الديناميكي للغة بين الإنجليزية والعربية:

- **مفتاح تبديل اللغة**: موجود في رأس الصفحة
- **الترجمة الفورية**: تبديل جميع عناصر الواجهة
- **دعم RTL**: اتجاه من اليمين لليسار للعربية
- **ملفات الترجمة**: `/src/locales/en.json` و `/src/locales/ar.json`

## 13. استكشاف الأخطاء وإصلاحها

### 13.1 المشكلات الشائعة

| المشكلة | السبب المحتمل | الحل |
|---------|---------------|------|
| لا يمكن تسجيل الدخول | كلمة مرور خاطئة أو حساب غير نشط | إعادة تعيين كلمة المرور أو الاتصال بالمدير |
| الموقع لا يظهر | خارج نطاق الصلاحيات | التحقق من الولاية/المحلية المعينة |
| فشل المطالبة بالموقع | خارج نطاق 80 كم أو تم المطالبة بالفعل | التحقق من الموقع الحالي |
| لا تتزامن البيانات | لا يوجد اتصال بالإنترنت | التحقق من الاتصال وإعادة المحاولة |
| رفض التكاليف | إيصالات ناقصة أو مبالغ غير صحيحة | مراجعة التعليقات وإعادة التقديم |
